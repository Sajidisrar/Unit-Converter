## What this was

A free online unit conversion site built with Next.js, covering measurement conversions (length, weight, temperature, area, speed, volume, time, pressure, angle), energy and power, cooking, fitness, fuel economy and data storage, plus hand-written landing pages for high-intent conversion pairs like `kg-to-lbs` and `celsius-to-fahrenheit`.

## Tech stack

- [Next.js 15](https://nextjs.org) (App Router) with React 19
- TypeScript
- Tailwind CSS v4
- Vitest for the conversion logic test suite

## Running it locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
