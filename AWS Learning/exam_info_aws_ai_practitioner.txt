================================================================================
         AWS CERTIFIED AI PRACTITIONER (AIF-C01) - EXAM GUIDE
================================================================================

EXAM OVERVIEW
-------------
  Exam Code:            AIF-C01
  Certification Level:  Foundational
  Cost:                 $100 USD
  Duration:             90 minutes (1 hour 30 minutes)
  Total Questions:      65
  Scored Questions:     50  (these count toward your score)
  Unscored Questions:   15  (pretest items - NOT identified on exam)
  Passing Score:        700 / 1000
  Score Range:          100 - 1000 (scaled scoring)
  Validity:             3 years
  Prerequisites:        None (AWS Cloud knowledge recommended)

  NOTE: You MUST answer all 65 questions. The 15 unscored questions
  are mixed in and cannot be identified. Treat every question as scored.


EXAM DELIVERY
-------------
  - Pearson VUE testing center (in-person)
  - Online proctored exam (from home/office)
  - ESL +30 minutes accommodation available for non-native English speakers

  Languages: English, Arabic, French, German, Italian, Japanese, Korean,
             Portuguese (Brazil), Spanish (Latin America & Spain),
             Simplified Chinese, Traditional Chinese


RECERTIFICATION
---------------
  - Valid for 3 years from exam date
  - Options: Retake AIF-C01 exam OR earn AWS Certified ML Engineer - Associate


================================================================================
                         QUESTION TYPES
================================================================================

  1. MULTIPLE CHOICE (most common)
     - One correct answer out of four options (A, B, C, D)

  2. MULTIPLE RESPONSE
     - Two or more correct answers from five or more options
     - Question specifies how many to select (e.g., "Select TWO")
     - No partial credit

  3. ORDERING
     - Arrange 3-5 items in the correct sequence

  4. MATCHING
     - Match responses to 3-7 prompts
     - Example: Match AWS services to their descriptions


================================================================================
                         SCORING DETAILS
================================================================================

  Score Range:        100 to 1000
  Passing Score:      700
  Scoring Model:      COMPENSATORY

  What "compensatory" means:
  - You do NOT need to pass each domain separately
  - Your OVERALL score across all domains determines pass/fail
  - Strong performance in one domain can compensate for weakness in another

  Scaled Scoring:
  - Raw scores are converted to a scaled score (100-1000)
  - Accounts for difficulty differences between exam versions
  - Passing always represents the same competency level

  Results:
  - Pass/Fail shown immediately on screen after completing exam
  - Detailed score report emailed within 5 business days
  - Score report shows overall score + performance per domain
    (Meets Competency / Needs Improvement)

DOMAIN 1: Fundamentals of AI and ML (20%)
------------------------------------------
  Task Statements:
  - Explain basic AI concepts and terminologies
  - Identify practical use cases for AI
  - Describe the ML development lifecycle

  Key Topics:
  - Types of AI: Narrow AI, General AI, Super AI
  - ML types: Supervised, Unsupervised, Reinforcement Learning
  - Deep Learning and Neural Networks
  - NLP and Computer Vision fundamentals
  - Training, validation, and test data splits
  - Overfitting, underfitting, bias-variance tradeoff
  - Key terms: features, labels, epochs, hyperparameters, inference
  - AWS AI/ML service stack overview


DOMAIN 2: Fundamentals of Generative AI (24%)
----------------------------------------------
  Task Statements:
  - Explain basic concepts of generative AI
  - Understand capabilities and limitations of GenAI
  - Describe AWS infrastructure for building GenAI applications

  Key Topics:
  - Foundation Models (FMs) concepts and characteristics
  - Large Language Models (LLMs) and Transformers
  - Tokens, embeddings, and vector databases
  - Amazon Bedrock overview and model providers
  - Amazon Titan models
  - Amazon Q (Q Business, Q Developer)
  - GenAI patterns: text, image, code generation
  - RAG (Retrieval Augmented Generation) concepts
  - Prompt engineering fundamentals
  - Inference parameters: temperature, top-p, top-k


DOMAIN 3: Applications of Foundation Models (28%)
--------------------------------------------------
  Task Statements:
  - Describe design considerations for FM applications
  - Choose effective prompt engineering techniques
  - Describe training and fine-tuning process for FMs
  - Describe methods to evaluate FM performance

  Key Topics:
  - Amazon Bedrock Knowledge Bases, Agents, Guardrails
  - Fine-tuning vs continued pre-training vs RAG vs prompt engineering
  - Amazon Bedrock fine-tuning capabilities
  - Model evaluation: BLEU, ROUGE, human evaluation
  - Amazon Bedrock Model Evaluation
  - Prompt techniques: zero-shot, few-shot, chain-of-thought
  - Prompt chaining and multi-step workflows
  - AWS AI services: Rekognition, Comprehend, Transcribe, Polly,
    Translate, Lex, Textract, Kendra, Personalize, Forecast
  - SageMaker for ML development
  - MLOps: SageMaker Pipelines, Model Registry
  - Cost optimization for AI/ML workloads


DOMAIN 4: Guidelines for Responsible AI (14%)
----------------------------------------------
  Task Statements:
  - Explain development of responsible AI systems
  - Recognize importance of transparent and explainable models

  Key Topics:
  - Responsible AI pillars: fairness, explainability, robustness,
    privacy, governance, transparency, safety
  - Bias types: selection, measurement, confirmation, historical
  - Fairness metrics and equity in AI systems
  - Explainability: SHAP, LIME, feature importance
  - AWS AI Service Cards
  - Amazon SageMaker Clarify
  - Human-in-the-loop with Amazon A2I
  - Model monitoring for drift and fairness degradation
  - Regulatory considerations: GDPR, EU AI Act


DOMAIN 5: Security, Compliance, and Governance (14%)
-----------------------------------------------------
  Task Statements:
  - Explain methods to secure AI systems
  - Recognize governance and compliance regulations for AI systems

  Key Topics:
  - AWS Shared Responsibility Model for AI/ML
  - Data encryption (at rest, in transit) for ML workloads
  - IAM policies for SageMaker and Bedrock
  - VPC configurations and network isolation
  - AWS PrivateLink for Bedrock
  - CloudTrail logging for AI services
  - Amazon Macie for sensitive data detection
  - Compliance: HIPAA, SOC, PCI DSS, GDPR
  - Model governance, lineage, versioning
  - AWS KMS encryption for ML artifacts

  Priority 5: Domain 5 - Security & Compliance              (12% study time)
              -> Overlap with general AWS security. Focus on AI-specific.


TIME MANAGEMENT DURING EXAM
----------------------------
  Total: 90 minutes for 65 questions = ~1 min 23 sec per question

  First Pass  (60 min): Answer confident questions. Flag uncertain ones.
  Second Pass (20 min): Return to flagged questions. Eliminate and choose.
  Final Review (10 min): Check remaining flags. Ensure nothing is blank.

  *** NEVER leave a question blank - NO penalty for guessing ***


================================================================================
                    ANSWER TECHNIQUES
================================================================================

  1. ELIMINATION METHOD
     Eliminate obviously wrong answers first. Even removing one option
     improves your odds from 25% to 33%.

  2. LOOK FOR AWS-PREFERRED ANSWERS
     AWS exams favor managed services over custom implementations.
     Bedrock > self-hosted models. SageMaker > raw EC2.

  3. KEYWORD SPOTTING
     Watch for: "MOST cost-effective", "LEAST operational overhead",
     "BEST", "FIRST". These qualifiers determine the correct answer.

  4. SCENARIO-BASED PATTERN
     "A company wants to..." questions:
     (1) Identify the requirement
     (2) Map it to an AWS service
     (3) Choose the simplest solution meeting ALL requirements

  5. READ ALL OPTIONS
     Never pick the first answer that looks right. Read ALL four options.
     The best answer might be D.

  6. WATCH FOR ABSOLUTES
     Be cautious of "always", "never", "only", "all" - these are often
     incorrect. AWS services have nuanced use cases.


================================================================================
                    COMMON TRAP TOPICS
================================================================================

  TRAP: Bedrock vs SageMaker confusion
  TIP:  Bedrock = managed access to FMs (no ML expertise needed)
        SageMaker = full ML platform (build/train/deploy custom models)

  TRAP: RAG vs Fine-tuning vs Prompt Engineering
  TIP:  Prompt Engineering = fastest, cheapest, try FIRST
        RAG = need current/proprietary data WITHOUT changing model
        Fine-tuning = need to change model behavior, have labeled data

  TRAP: Confusing AWS AI services
  TIP:  Comprehend = NLP text analysis
        Rekognition = image/video analysis
        Textract = document OCR/extraction
        Transcribe = speech-to-text
        Polly = text-to-speech
        Translate = language translation
        Lex = chatbots
        Kendra = intelligent search
        Personalize = recommendations
        Forecast = time-series predictions

  TRAP: Bias types confusion
  TIP:  Selection bias = non-representative sample
        Measurement bias = flawed data collection
        Historical bias = real-world inequalities in data
        Confirmation bias = favoring existing beliefs

  TRAP: Inference parameters
  TIP:  Temperature = randomness (higher = more creative)
        Top-p = cumulative probability threshold
        Top-k = number of top tokens to consider
        Max tokens = output length limit

  TRAP: Shared Responsibility for AI
  TIP:  AWS secures infrastructure
        YOU secure: data, IAM, encryption, model I/O, app security

================================================================================
                       EXAM DAY TIPS
================================================================================

  - Arrive 15 min early (testing center) or test system beforehand (online)
  - Bring two valid IDs (testing center) or have one ready (online)
  - Read each question TWICE before answering
  - Flag difficult questions and come back - don't waste 5 min on one question
  - Answer EVERY question - no penalty for wrong answers
  - Trust your first instinct unless you find a clear reason to change
  - Use strike-through to eliminate wrong answers visually
  - If two answers seem right, choose the MORE specific one
  - Take a deep breath if rushed - 90 minutes is enough with good time mgmt
